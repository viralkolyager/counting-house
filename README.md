# Бухгалтерия (counting-house)

Решения упражнений к разделу «Арифметика с плавающей запятой»: IEEE754, `decimal`, `fractions`.

Нужен Python 3.10+ и (для упражнения №3) `matplotlib`:

```bash
pip install -r requirements.txt
```

## №1. Машинное эпсилон

Делим `eps` пополам, пока `1.0 + eps/2 != 1.0`.
Результат: `2.220446049250313e-16 = 2**-52` — совпадает с `sys.float_info.epsilon`.
Для одинарной точности: `2**-23 ≈ 1.19e-07`.

## №2. Рекурсия Мюллера

`f(y, z) = 108 - (815 - 1500/z) / y`, `x0 = 4`, `x1 = 4.25`.

**а)** Во `float` получается `x30 = 100.0`.

**б)** Неподвижные точки — корни `(x-3)(x-5)(x-100) = 0`. Подстановка `x_n = u_{n+1}/u_n`
даёт линейную рекурсию с решением `u_n = a·3^n + b·5^n + c·100^n`. Начальные условия
дают `a = b`, `c = 0`, то есть

```
x_n = (3^(n+1) + 5^(n+1)) / (3^n + 5^n)  →  5
```

Точное значение `x30 ≈ 4.9999995578522585`. (В тексте курса написано «должно было
получиться 4» — это опечатка: 4 — начальное значение, предел равен **5**.)

**в)** `c = 0` выполняется только в точной арифметике. Из-за округления появляется
крошечная составляющая `c·100^n`, которая растёт в `20^n` раз быстрее правильной.
Точка 100 притягивающая, точка 5 — отталкивающая, поэтому ошибки округления
неизбежно уводят последовательность к 100.

## №3. Ипотека

```bash
py ex3_mortgage.py 3000000 12 15          # S, x% годовых, y лет
py ex3_mortgage.py 3000000 12 15 --no-show --no-table
```

- платёж `P = S·r / (1 − (1+r)^−12y)`, `r = x/12/100`, округлён вверх до копейки;
- последний платёж закрывает остаток и немного меньше остальных;
- выводит переплату, таблицу (остаток, платёж, проценты, основной долг);
- сохраняет графики `balance.png` и `payments.png`.

Пример: 3 000 000 ₽ под 12% на 15 лет → платёж 36 005,05 ₽, переплата 3 480 904,84 ₽.

## №4. Decimal и Fraction

- `Decimal` с точностью 28 знаков тоже уходит к 100 — это всё ещё арифметика
  с округлением. Нужно больше ~50 знаков, чтобы `x30` был верным.
- `Fraction` считает точно: `x30 = 2328306745375394431036/465661390253305305137`,
  и это в точности совпадает с аналитической формулой.
